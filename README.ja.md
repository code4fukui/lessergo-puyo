# lessergo-puyo

鯖江市西山動物園の開園40周年を記念して制作された、レッサーパンダの顔をモチーフにしたぷよぷよゲームです。本ゲームは同園が提供するオープンデータのアセットを活用しています。

## デモ

ブラウザ上で直接プレイできます:
**[lessergo-puyoをプレイ](http://ww31.tiki.ne.jp/~vz5yjpqo/sabae/)**

## 特徴

- **レッサーパンダテーマ:** 鯖江市西山動物園のCC BYライセンスで提供されているレッサーパンダの画像と鳴き声を使用しています。
- **クラシックなゲームプレイ:** スコア計算、連鎖（コンボ）、全消し（オールクリア）ボーナスなど、おなじみのぷよぷよのシステムを実装しています。
- **レスポンシブな操作:** キーボードの矢印キー、またはタッチデバイスでのスワイプ操作に対応しています。
- **ダイナミックなサウンド:** 連鎖時に2種類の異なる効果音が鳴ります。
- **カスタマイズ可能:** `src/config.js`を編集することで、落下速度、盤面のサイズ、ぷよの種類数などのゲームパラメータを簡単に変更できます。

## はじめに

1. このリポジトリをクローンします。
2. 最新のウェブブラウザで `index.html` を開いてプレイします。

### アセットのダウンロード（オプション）

このリポジトリには必要な画像および音声アセットがすべて含まれています。もし不足している場合は、同梱のDenoスクリプトを使用してデモサーバーからダウンロードできます。

1. [Deno](https://deno.land/) をインストールします。
2. プロジェクトのルートディレクトリから以下のスクリプトを実行します:
    ```sh
    deno run --allow-net --allow-write tool/download.js
    ```

## 遊び方

- **移動:** 左右の矢印キー、または左右にスワイプ
- **回転:** 上の矢印キー、または上にスワイプ
- **高速落下:** 下の矢印キー、または下にスワイプ

## データと権利表記

- **レッサーパンダのアセット:** 画像および鳴き声は、鯖江市西山動物園のオープンデータ（CC BY）を使用しています。
- **ゲームロジック:** ぷよぷよのルールは、公式の[ぷよぷよeスポーツ×プログラミング](https://puyo.sega.jp/program_2020/)の教材を参考に実装しています。
